# Triage vocabulary

Local tickets use these strings on their `Status:` line.

| Canonical role | Local value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Requires evaluation |
| needs-info | needs-info | Missing a consequential answer |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Deliberately not being pursued |

Execution states and the separate wayfinding lifecycle are defined in
[issue-tracker.md](issue-tracker.md). These are local conventions; this setup does
not create labels in a remote service.
