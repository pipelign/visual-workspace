# Neutral brand

Use the described semantic roles in `brand.json`. The owner-defined
`workflowAccent` labels the workflow; fixed imagery retains its original color.
Inter regular is a local, licensed font supplied by the pinned @fontsource/inter
package. This example is a neutral starting point, not owner-approved artwork.

Both variations communicate the same content. New variations supply values for
every role without copying composition source. Typography roles refer to local
WOFF2 resources; the renderer embeds the font and its license in each delivery.
